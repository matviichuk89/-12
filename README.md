Лабораторна робота №12 учня факультету комп'ютерні науки 1 курса 9 групи Матвійчук Назар Віталійович Варіант 13

1. Користувач задає рядок слів, розділених пробілами. Програма повинна: 
1) дописати у кінці кожного слова випадковий розділовий знак і вивести рядок 
на екран; 2) вивести у стовпчик всі слова, які повторюються. З цією метою 
написати 2 функції.
2. Серійний номер акумуляторної батареї складається з серії (велика 
англійська літера – A, E, U, F, Q, R, Z або W), 8 випадкових десяткових цифр 
(від 0 до 9), дефісу і значення напруги (3, 6 або 12). Програма повинна записати 
у файл N таких номерів і розташувати їх у порядку зростання. Для генерування 
одного номера створити функцію.
3. Написати модуль з функціями: 1) для визначення суми цифр 
натурального числа; 2) для визначення найбільшої цифри натурального числа; 
3) для визначення найменшої цифри натурального числа. Підключити модуль 
до основної програми і виконати відповідні обчислення.
